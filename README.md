# موقع مواقيت الصلاة - شبوة

موقع عربي ثابت مجاني على GitHub Pages، مستقل عن تطبيق الحسابات.

## تشغيل الموقع
افتح `index.html` في المتصفح مباشرة لمعاينة التصميم.

## نشر الموقع مجانًا
1. أنشئ مستودع GitHub جديدًا، مثل `shabwah-prayer-times`، واجعله Public.
2. ارفع `index.html` و`config.js` إلى جذر المستودع.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)` واحفظ.
4. سيصبح الموقع متاحًا عادةً على `https://USERNAME.github.io/REPO/`.

## تفعيل تحميل APK
1. من المستودع الجديد افتح Releases → Draft a new release.
2. ارفع ملف APK الصادر من مشروعك باسم `app-release.apk`، وأنشئ Tag مثل `v1.0.0`، ثم Publish release.
3. عدّل `config.js` وأدخل `githubOwner` و`githubRepo` الخاصين بالمستودع الجديد.
4. ادفع التعديل إلى GitHub. ستعمل أزرار التنزيل والتحديث على أحدث ملف APK عند توفره.

> أزرار التحميل معطّلة عمدًا حتى تضع مستودعًا صحيحًا؛ لا يوجد رابط APK مفترض أو وهمي.

## ملاحظات
- الموقع لا يحتاج قاعدة بيانات أو استضافة مدفوعة.
- رسم الهاتف في الموقع توضيحي وليس لقطة شاشة حقيقية.
- تحديث التطبيق دون فقد البيانات يتطلب نفس applicationId ومفتاح التوقيع، مع رفع versionCode.
- يمكن استبدال الرسم بصورة حقيقية للتطبيق لاحقًا.

## تغيير صورة التطبيق
ضع صورة التطبيق الجديدة باسم `app-preview.jpg` بجانب `index.html`، وستظهر تلقائيًا في واجهة الموقع. يُفضّل صورة طولية واضحة.

## وضوح أزرار التحميل
تم تعديل الألوان والخطوط لإظهار نص التحميل والتحديث بوضوح، حتى قبل ربط GitHub Releases.

## حقوق التطوير
تظهر عبارة «تطوير وبرمجة Yemen DevTech» في تذييل الموقع. الموقع مستقل ولا يتضمن روابط تطبيق الحسابات.
